01 / Калькулятор ↗

[ 01 / Калькулятор ]

Калькулятор стоимости каркасного дома

Приложение для расчёта стоимости строительства по параметрам дома и актуальному прайсу.

Задача
Учитывать пожелания клиента и собирать подробную смету в одном интерфейсе.
В проекте
Параметры дома, детализация затрат, загрузка прайса из Excel/CSV, экспорт сметы и сохранение проектов.
Приложение для WindowsРасчёт сметы

Проект представлен скриншотами.

Подробнее: исходные данные проекта +

В основе расчётов — справочник затрат: разделы строительства, наименования работ и материалов, единицы измерения и цены. В предоставленном примере цены скрыты.

Трекерная / инструменты на каждый день

Самостоятельные MVP по публичным заданиям. Без участия и приёмки заказчиков. Проекты представлены скриншотами.

02 / Ритм ↗

Ритм / трекер привычек

Добавление привычек, отметки по дням и обзор регулярности за неделю.

Самостоятельный MVPТрекер привычек
Скриншоты и возможности +

Недельный календарь, серия выполнений, редактирование привычек и экспорт CSV. Данные хранятся локально в браузере, без облачной синхронизации.

03 / Счёт ↗

Счёт / трекер расходов

Учёт расходов по категориям: журнал операций, итоги месяца и средний расход.

Самостоятельный MVPУчёт расходов
Скриншот и возможности +

Добавление суммы, категории, даты и комментария. Выбор месяца, редактирование записей, распределение расходов по категориям и экспорт CSV. Локальное хранение в браузере, без облачной синхронизации.

04 / Фокус ↗

Фокус / трекер времени

Таймер рабочих сессий, ручные записи и журнал времени по проектам.

Самостоятельный MVPУчёт времени
Скриншоты и возможности +

Запуск и сохранение сессии, ручное добавление и редактирование записей, итоги дня и недели, экспорт CSV. Таймер считает прошедшее время; он не определяет активность пользователя. Данные хранятся локально в браузере.
