# Портфолио Анны

Статическая версия для GitHub Pages. Дизайн и опубликованные работы перенесены из локального портфолио.

Форма подготавливает письмо на annay22_gav@mail.ru; пользователь подтверждает отправку в своём почтовом приложении. Также доступно копирование текста заявки. Серверная админка и запись в Google Таблицу в этой версии не используются.

Публикация: Settings → Pages → Deploy from a branch → main → /(root) → Save.

Пароли, ключи, настройки почты и Google Таблицы в репозитории отсутствуют.
