# Портфолио Анны

Статический сайт на GitHub Pages: https://goncharovaanna1311-hue.github.io/anna-portfolio-pages/

Форма заявки встроена из Google Apps Script. После нажатия «Отправить заявку» обработчик проверяет поля и сохраняет строку в закрытой Google Таблице. Успех показывается только после подтверждения сервера. Есть защита от повторной записи по ID, ограничение частоты, поле-ловушка и сохранение текста при ошибках. Для работы требуется JavaScript и доступ к сервисам Google. В модальном окне есть ссылка на отдельную форму и резервный email.

Запись содержит дату, имя, email, услугу, задачу, статус, ID и источник. В исходниках GitHub Pages нет секретов Google или токенов. Существующий секрет защищённого вебхука остаётся только в Apps Script.

Вызов формы с карточки услуги выбирает услугу при первом открытии. При повторном открытии форма сохраняет введённые данные; услугу можно изменить вручную. После успешной отправки доступна кнопка «Новая заявка».

Публикация: Settings → Pages → Deploy from a branch → main → /(root). Серверная админка в статическую версию не входит.
